# Tesztek leírása

A képeken a diff parancs használatával jól látható, hogy a fájlok közötti változás csak a kommenteket érintette.

Továbbá az LLM azt is észlelte, hogy a kontextustól teljesen elkülönülő rossz komment volt megadva, ezt törölte is.

Saját tesztjeim alapján a modellek jól válaszolnak, és ez az újabb modellekkel egyre csak jobb lehet. Ennek ellenére is fontos az hogy mindig felülvizsgáljuk a generált kommentet.
